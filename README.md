# OpenDrone

An open-source FPV drone flight simulator. Its flight physics stay faithful to real-world quads, with optional Assists layered on top.

Start with [`CONTEXT.md`](CONTEXT.md), the map of how OpenDrone is described and built. To work on it, see [`CONTRIBUTING.md`](CONTRIBUTING.md).
